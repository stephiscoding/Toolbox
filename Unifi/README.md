# Unifi Scripts
You will need to set environment variables for credentials - see the scripts to know which ones.

`.env` file example:
```
CONTROLLER_URL=
USERNAME=
PASSWORD=
API_KEY=
```

## Mute All Cameras
Disables **all** cameras at **all** accessible sites (the API key *must* be generated by a user who is the owner of the sites you want this to apply to.)

## Count all devices
Take a guess.

## Set Power Level To Low
Sets the broadcast power of **all** APs to low. Used for compliance purposes. 

## Get all devices
Gets some basic info for all devices on a per site basis, and dumps it into a CSV.

## Find Device by MAC
Finds a device given a MAC, and gives you some basic information about it - the name, what site it is adopted to, etc. 

Takes positional command line arguments:
- The MAC address of the device
- The verbosity you want: leave it unset to just find the site it's adopted to and it's name. Add "vv" to the command to print out the full device info. (Be warned - it's a lot!)

Example:
```bash
python find_device_by_MAC.py d8:b3:75:a5:26:9c vv
```
